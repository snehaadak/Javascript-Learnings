
- **Higher Order Functions:**
    - Higher-order functions are functions that can either accept other functions as arguments, return a function as a result, or both.
    - for Eg:
        function x(){
            console.log("Hello World!")
        }

        function y(x){
            x();
        }

        in this case we have a independent function x which is passed in as an argument to function y hence we can say that function y is the Higher Order Function. and x would be the callback function

- **Why do we need Higher Order Functions with eg**

    - Let us consider we are given an array of 4 radius of a circle

        const radius = [3, 1, 2, 4];

    - Now if we are asked to calculate the area of each circle, the below code will give us the array of areas:

        function area(radius){
            const output = [];
            for (let i=0; i< radius.length; i++){
                output.push(Math.PI * radius[i] * radius[i])
            }
            return output;
        }
        console.log(area(radius))

    Now if we are asked to calculate the circumference and diameter of circle we would usually do the below codes in continuation by copy pasting the above parts:

        function circumference(radius){
                const output = [];
                for (let i=0; i< radius.length; i++){
                    output.push(2 * Math.PI * radius[i])
                }
                return output;
            }
            console.log(circumference(radius))

         function diameter(radius){
                const output = [];
                for (let i=0; i< radius.length; i++){
                    output.push(2 * radius[i] )
                }
                return output;
            }
            console.log(diameter(radius))

    - But this is not the correct way of coding we should follow a simple principle i.e *DRY: Don't repeat yourself* which means we should not repeat the codes and rather use the modular coding method or reusuable code.

    - Hence we will write a reusable and clean code without repeating:

        const radius = [ 3, 1, 2, 4]
        const area = function(radius){
           return Math.PI  * radius * radius}
        const circumference = function(radius){
           return 2 * Math.PI  * radius}
        const diameter = function(radius){
           return 2 * radius}

        const calculate = function(radius,logic){
            const output = [];
            for(let i=0; i< radius.length ; i++){
                output.push(logic(radius[i]))
            }
            return output;
        }

        console.log(calculate(radius,area))
        console.log(calculate(radius,circumference))
        console.log(calculate(radius,diameter))

    - So in above case we have the higher order function calculate in which we are passing the area, circumference and diameters logic as arguments. Hence we have made our code reusable.
