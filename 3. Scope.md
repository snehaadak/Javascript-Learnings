- **Scope**
    - Scope means where we can access a specific variable or a function in our whole code. 
    - Scope in Javascript is directly related to the lexical environment
    - Understanding with below code eg:

        function a(){
            console.log(b);     ---------> [ 10 ]
        }
        var b = 10;
        a();

     for above code b is declared in the global scope yet it will print when called inside of the function a. Because when it is called to console inside of function a JS first searches for the b varible inside its own execution context. if not found inside of that it moves to the outer environment. In our case it moved outside the execution context of a i.e the global execution context. Hence fetched the value of b.

- **Lexical Environment**
    - Lexical individual as term means hierarchy.
    - Lexical Environment is the combination of the local memory + lexical environment of its parent
    - Understanding with below code Eg:
        function a() {
            function c(){
                console.log(b)
            }
            c();
        }
        var b = 10;
        a();

        For above code we can say that function c() is lexically sitting inside function a() OR in generic terms we can say funct c is in hierarchy with funct a OR where is funct c(); pysically present i.e. inside of function a.
        and function a is lexically inside the global scope

    - So when we say `lexical Environment` it means the local memory and the lexical environment of it parent (in which the code is physically present)

    - Every execution context created has the reference to its parent's lexical environment.

    - for above eg: when the console.log is used for b inside funct c it tries to search for b in its local memory of c as it is not present it will use the reference to parent's lexical environment that in our case is function a it will try to search for variable b in it if its not there it will use the reference to a's parent lexical environment i.e the global scope and search for b in it and if found it will console logs it if not found it shows undefined.

 - The above way of searching from bottom to top of hierarchy of lexical environments is known as `scope chain`.
