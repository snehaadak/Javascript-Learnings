
*Map, Filter & Reduce: are the Higher order functions.*

- **Map: [].map()**
    - Map function is used to transform a given array i.e use the current array's val;ue and get the whole new array out of it.
    - For eg: if have a given array 
        const arr = [5, 1, 3, 2, 6];

        and we want to get the whole set of new arrays from the above array

        Double of arr - [10, 2, 6, 4, 12]
        Triple of arr - [15, 3, 9, 6, 18]
        Binary of arr - ["101", "1", "11", "10", "110"]
    - syntax:
        const newOutputArr = arr.map(function)
            where newOutputArr is the new transformed arr to be found, arr is the already given array and function passed inside is the action that we want to perform on arr to get the new arr in our above eg case the function would be to double the value, triple the value or find binary.

            function double(x){
                return x * 2;
            }

            function triple(x){
                return x * 3;
            }

            const doubleArr = arr.map(double);
            console.log(doubleArr)      --> [10, 2, 6, 4, 12]

            const tripleArr = arr.map(triple);
            console.log(tripleArr)      --> [15, 3, 9, 6, 18]

    - Even below eg is the valid Syntax
            const binaryArr = arr.map(function binary(x){
                return x.toString(2);
            });
            console.log(binaryArr)      --> ["101", "1", "11", "10", "110"]


- **Filter: [].filter()**
    - filter function is used to filter out the given array as per the need.
    - For Eg: to get a new filtered(odd, even, greater than 4) arrays from arr = [5, 1, 3, 2, 6]

        function isOdd(x){
            return x % 2 !== 0 ;
        }
        const oddNumbsArr = arr.filter(isOdd)
        console.log(oddNumbsArr)        --> [5, 1, 3]

        const evenNumbsArr = arr.filter(function isOdd(x){
            return x % 2 === 0 ;
          })
        console.log(evenNumbsArr)        --> [2, 6]

        const greaterThan = arr.filter((x) => {
            return x > 4 ;
          })
        console.log(greaterThan)        --> [5, 6]


- **Reduce: [].reduce()**
    - Reduce function is used where we have to take all the elements of array and convert it to a single element as an output i.e come up with single value out of them.
    - syntax:
            const output = arr.reduce(function(acc,cur),initialvalue of acc)
        where output would be the single reduced value, of given array arr which takes two parameters the function and the intial w=value of accumulator and ahead the function also has two parameters thats are acc the *accumulator* and cur the *current*
    - for eg: To find the sum of the array elements or max of the entire array elements.

        `Without using the reduce function`
            function findSum(arr){
                let sum = 0;
                for(let i=0; i< arr.length; i++){
                    sum = sum + arr[ i ];
                }
                return sum
            }
            console.log(findSum(arr));    --> [ 17 ]

            function findMax(arr){
                max = 0
                for(let i =0; i< arr.length; i++){
                    if(arr[ i ] > max){
                        max = arr [ i ]
                    }
                }
                return max; 
            }
            console.log(findMax(arr));     --> [ 6 ]

        `With Reduce Function`
            const sum = arr.reduce(function(acc,curr){
                acc = acc + curr;
                return acc;
            },0);
            console.log(sum)                --> [ 17 ]

            const output = arr.reduce(function(max,curr){
                if(curr > max){
                    max = curr
                }
                return(max)                
            },0)
            console.log(output)             --> [ 6 ]
