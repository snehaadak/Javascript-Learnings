
*Map, Filter & Reduce: are the Higher order functions.*

- **Map: [].map()**
    - Map function is used to transform a given array i.e use the current array's val;ue and get the whole new array out of it.
    - For eg: if have a given array 
        const arr = [5, 1, 3, 2, 6];

        and we want to get the whole set of new arrays from the above array

        Double of arr - [10, 2, 6, 4, 12]
        Triple of arr - [15, 3, 9, 6, 18]
        Binary of arr - ["101", "1", "11", "10", "110"]
    - syntax:
        const newOutputArr = arr.map(function)
            where newOutputArr is the new transformed arr to be found, arr is the already given array and function passed inside is the action that we want to perform on arr to get the new arr in our above eg case the function would be to double the value, triple the value or find binary.

            function double(x){
                return x * 2;
            }

            function triple(x){
                return x * 3;
            }

            const doubleArr = arr.map(double);
            console.log(doubleArr)      --> [10, 2, 6, 4, 12]

            const tripleArr = arr.map(triple);
            console.log(tripleArr)      --> [15, 3, 9, 6, 18]

    - Even below eg is the valid Syntax
            const binaryArr = arr.map(function binary(x){
                return x.toString(2);
            });
            console.log(binaryArr)      --> ["101", "1", "11", "10", "110"]
