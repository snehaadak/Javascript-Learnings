- **Difference between var, let & const**
    - `Hoisting`: var is hoisted, let & const are not hoisted.
    - `Declaration`: we can redeclare var. but we cannot redeclare a let & const variables.
    - `Initialization`: const is even more stricter than let we can't even reinitialize the const values. we need to initialize the value where const is declared there itself.
    - let & const are blocked scoped.


- **Hoisting for let & const**

    - for eg: 
        console.log(a);  --> [ throws a "Reference Error" ]
        console.log(b);  --> [ undefined ]
        let a = 10;
        console.log(a);
        var b = 100;

        We say var is hoisted because it won't throw error if we call it before it is initialized in the code. But incase of let it would throw a reference error because it is not hoisted. which means we can only access the let a after initialization

    - `var` is hoisted in the global object. whereas the memory allocation for `let` & `const` happens in the separate object which cannot be accessed before it has some value initialized to it.


- **Temporal Dead Zone**
    - It is a time since when this let variable was hoisted upto when it is initialized some value.
    - in our above example everything above the let a = 10 is the temporal dead zone for the variable a. hence that error.


- **Types of errors** - *Type Error, Reference Error, Syntax Error*
