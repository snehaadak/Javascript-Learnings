
- **Closure**
    - A Closure is the combination of a function bundled together(enclosed) with references to its surrounding state(lexical environment) or Closure means a function bind together with its lexical environment
    - In other words, a closure gives you access to another function's scope from an inner function.
    - for eg:
        function x(){
            var a = 7;
            function y(){
                console.log(a);
            }
            y();
        }
        x();

    y forms a closure because it is binded with the variable of its lexical scope (function x). i.e. variable a

- **setTimeout**
    - function x() {
        var i = 1;
        setTimeout(function(){
            console.log(i);
        }, 3000);
        console.log("Hello World!")
    }
    x();
    -  In above piece of code the setTimeout function forms the closure and and saves up its lexical environment's reference to variable i. when the above code is executed as the setTimeout function is set to 3000ms (3sec) it stores it as a closure with the reference to var i and moves ahead with the rest of the code and hence first prints Hello world! and then after 3 secs again the setTimeout function is pushed into callstack and executed printing 1.
