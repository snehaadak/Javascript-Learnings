- **Function Statement/Function declaration:**
    - A normal way of declaring a function is called a function statement
    - Also known as function declaration.
    - for eg:
        function a(){
            console.log("a called")
        }


- **Function Expression:**
    - we can assign a function to a variable, where a function acts as a value. This assignment of function a variable is called Function Expression.
    - for eg:
        var b = function a(){
            console.log("a called")
        }
    - *Difference between the normal function statement and a function expression is of hoisting*. If we call a function a and b before they are created in very start the function a will be executed weheras the b will throw an error because it is a varibale and hoisting for a variable is undefined and it says that the b is not a function yet it will be treated as variable.


- **Anonymous Function:**
    - A function without a name is called a anonymous function.
    - Anonymous functions don't have there own identity
    - for eg:
        function(){

        }

    running the above code directly will result in the syntax error because a function statement requires a function name.
    - Hence anonymous functions are used in the places where the functions are to be used as values. for eg:
            var b = function (){
                console.log("a called")
            }


- **Named Function Expression:**
    - Named function Expression is simply giving the name to an anonymous function
    - for eg: 
        var b = function xyz(){
                console.log("b called")
            }
        b();        --> [ a called ]
        xyz();      --> [ Error: xyz is not defined ]
    in above code we have assigned a xyz function to a b variable and to call this xyz function we can only do it through by calling b(); and doing xyz(); as error mentioning xyz is not defined. This is because when we use a function as a value that xyz is not created in the outer scope/global scope but created as a local variable


- **Difference Between Parameter and Arguments:**
    - When we create a function in first place whatever local variables we assign to the function are known as `Parameters`.
    - Whatever values we pass to the function when it is called are known as `Arguments.`
