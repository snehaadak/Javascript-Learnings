- **Handling the Error**
    - Just like we have .then functionality for promise we have `.catch` for better error handling
    - .catch also takes in the function that takes error as parameter and further we can use that `parameter.message` to be console logged.

            promise.then(function(orderID){
                console.log(orderID)
            })
            .catch(function(err){
                console.log(err.message)            --> [ Cart is not Valid ]
            })

    - This is the graceful way of handling the error
